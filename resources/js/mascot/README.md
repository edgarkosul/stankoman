# Маскот чата

Анимированный робот, который служит лицом консультанта на кнопке чата.

## Файлы

| файл | что |
|---|---|
| `robot-head.source.svg` | вербатим-вырезка `<svg>` из демки, 244 КБ — **исходник, не трогать руками** |
| `robot-head.svg` | результат SVGO, 70 КБ — именно он едет в браузер |
| `svgo.config.mjs` | конфиг прогона |
| `robot-mascot.js` | движок анимации (форк `dev-scripts/bot-image/robot.js`) |
| `mascot-loader.js` | ленивая подгрузка и подмена плейсхолдера |

Живой стенд, на котором маскота видно в полный рост и можно крутить параметры, —
`dev-scripts/bot-image/index.html`, открывается файлом в браузере.

## Перегенерация

SVGO нужен только здесь и только разово, поэтому в `package.json` его нет —
результат лежит в репозитории:

```
node /home/edgar/dev/blog-siteko/node_modules/svgo/bin/svgo \
  --config resources/js/mascot/svgo.config.mjs \
  -i resources/js/mascot/robot-head.source.svg \
  -o resources/js/mascot/robot-head.svg
```

Нет соседнего проекта под рукой — `npx svgo@3` с тем же конфигом.

Замер на 12.09.2026: 243 704 B → **73 589 B** (gzip 30 584 B), 202 пути, 18 id,
11 групп, обводка на 196 путях. Если после прогона цифры сильно разошлись —
смотреть, не поехал ли пресет SVGO.

## Швы

Артворк обведён по растру: соседние фигуры стыкуются встык, не перекрываясь.
На каждой границе обе сглаживают свой край независимо, и четверть фона проходит
насквозь — на белой странице незаметно, на цветной читается как грязь по всей
голове. `convertPathData` эту беду усугубляет: замер растеризацией дал 197 узких
щелей в исходнике и 445 после оптимизации.

Лечит это плагин `seamStroke` в конфиге: каждый контур обводится своим же цветом
заливки, обводка расширяет фигуру на половину толщины в каждую сторону, соседи
перекрываются. Осталось 24 щели из 445.

Точностью это НЕ лечится. Прогон по вариантам:

| floatPrecision | узких щелей | размер |
|---|---|---|
| 0 | 445 | 70 КБ |
| 1 | 445 → 33 дыры | 168 КБ |
| 2 | как в исходнике | 230 КБ |

То есть вернуть качество исходника можно только отказом от оптимизации целиком.

## Что нельзя ломать

`robot-mascot.js` ищет узлы по id, поэтому в конфиге отключены `cleanupIds`,
`collapseGroups` и `removeViewBox`. После любой правки конфига проверять:

```
grep -o 'id="[^"]*"' robot-head.svg | sort | wc -l     # должно быть 18
grep -o 'url(#[^)]*)' robot-head.svg | wc -l           # должно быть 6
```

Все id с префиксом `km-`: он изолирует `clip-path: url(#…)` от чужой разметки
страницы — id в SVG глобальны для всего документа.

## Почему не в `resources/svg`

Там живут blade-icons (`config/blade-icons.php`, префикс `icon`): любой svg
оттуда становится компонентом `<x-icon-...>` и попадает в сканер. Маскот —
не иконка, а ассет, который импортируется из JS и версионируется Vite.
