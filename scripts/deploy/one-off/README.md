# Разовые переносы к первому выкату бота

Здесь лежит то, что **выкат не привезёт сам**: содержимое базы, а не код.
Файл выполняется один раз, на проде, сразу после первого выката ветки бота.

Почему он вообще есть: статьи базы знаний живут в таблицах. Код приедет
с релизом, миграции создадут пустые таблицы — и бот заговорит без единой
статьи, то есть на каждый вопрос об условиях магазина позовёт менеджера.
Заметить это можно, только прочитав его ответы, поэтому переносим сразу.

## Статьи базы знаний

`kb-content-2026-09-29.php` — 17 статей в трёх разделах, написанных по ответам
владельца из анкеты «ИИ бот → Вопросы для бота» (отправлена 27.09.2026)
и по тому, что видно на самом сайте.

```
php artisan tinker --execute="require 'scripts/deploy/one-off/kb-content-2026-09-29.php';"
php artisan ai:kb-reindex
```

Реиндекс обязателен: фрагментов и векторов в файле нет, они считаются на месте
и стоят копейки.

Повторный запуск безопасен — статьи ищутся по заголовку и переписываются.

## Когда это удалять

После первого выката и проверки. Дальше статьи ведёт владелец в админке,
и файл становится снимком прошлого: чем дольше он лежит, тем сильнее
расходится с тем, что бот говорит на самом деле.
